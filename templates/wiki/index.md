# INDEXX wiki

Start here. Keep this directory of pages current during authorized ingestion: each entry should have a link, a brief description, and source counts where useful. Record dated changes in [the log](log.md). Source media and transcripts remain in the library's `media/` tree.

## Sources

Add cited summaries from `sources/instagram/` here.

## People

Add evidence-supported person pages from `entities/people/` here. A person can appear across several uploader accounts. Review coverage separately; missing annotations do not prove absence.

## Creators

Add uploader pages from `entities/creators/` here. An uploader is not automatically the speaker.

## Concepts

Add shared ideas from `concepts/` once supported by at least three sources, or on an explicit user request. Update summaries and cross-references as new evidence arrives; preserve cited disagreements.

## Syntheses

Add cited answers saved at the user's request under `syntheses/`.

## Local watch views

Add requested generated lists under `views/`. They are snapshots: rebuild the local search index and regenerate after changes. Open the full library as an Obsidian vault for local media embeds, or open a generated HTML view in a local browser. These views do not establish playback inside Grok chat.
